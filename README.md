# 浅草石フリマ マイマップ（分割版）

GitHub Pagesで動作する静的Webサイトです。公開用ファイルは5つだけです。

- `index.html`: 画面の骨組み。ファイル名は必ず **index.html**
- `styles.css`: 色や表示デザイン
- `app.js`: 検索、タップ、訪問順、お気に入り、拡大縮小、バックアップ入出力
- `shops.json`: **店舗データ**。開催ID、日付・出展者名・ブース番号・ジャンル
- `map.json`: **会場データ**。日にち・階・各ブース番号・色・位置・壁・入口・受付

## 次回の使い方

配置とブース番号が今回と同じであれば、`shops.json` の `eventId`, `dates`, `shops` を新開催の情報に差し替えるだけで動かせます。
ただし、通路・ブースの区画数や位置が変わったら `map.json` も更新してください。
HTML/JS/CSSは通常更新不要です。

## 記憶ファイルについて

お気に入り・メモ・訪問済・訪問順は、iPhoneのSafariの localStorage に自動保存されます。
「記録をバックアップ」で **memory-...json** をiPhoneに書き出し、別端末では「記録を読み込む」から復元できます。
**個人記録のJSONはGitHubのPublicリポジトリにアップロードしないでください。**

初めて分割版を開いたときは、v19～v21の古い `asakusa-ishi-v3` キーから記録を一度引き継ぎます。
同一のSafari・同一のGitHub Pagesドメインで開いてください。プレビューや別ドメインの記録は自動移行できません。

## iPhoneでのアップロード

GitHubのリポジトリのルートに `index.html`, `app.js`, `styles.css`, `shops.json`, `map.json` の5ファイルを追加します。
複数ファイルを選択するか1つずつアップロードしてください。元の `index.html` は置き換えてください。
更新後、GitHub Pagesのサイトを開き、古い表示なら `?v=22` をURL末尾につけて確認してください。

## ローカル実行

`fetch()` で JSONを読むため `file://` 直開きは環境によって動きません。GitHub Pages等のHTTP(S)経由で実行してください。


## 画面の整理（v22）

地図を最初に見られるように、タイトル直下には開催日・階・検索・表示切り替えだけ置きました。
凡例・会場案内・公式リンク・記録のバックアップは、地図の下に折りたたみ式で配置しました。
表示件数は下部、地図の操作説明も下部に移し、ズームボタンは短くしました。
地図座標・店舗データ・記録の保存キーは変更していません。

**更新時**: `index.html`、`styles.css`、`app.js` の3ファイルをGitHubリポジトリのルートで上書きしてください。
`shops.json` と `map.json` は今回変更していないので、そのまま使えます。
一括アップロードしたい場合はZIPを展開し、5ファイルをリポジトリのルートへ配置します。
