# 石フリママップ v24：出展日表示

お気に入り一覧と店舗一覧に「20日のみ」「21日のみ」「両日」を追加しました。出展日の判定は shops.json 内の両日の店舗名を照合しています（フロア・ブース番号は変わっていても両日と判定します）。

## GitHubへの更新
既存のリポジトリの同じ階層で `index.html`、`app.js`、`styles.css` の3つを上書きしてください。`shops.json` と `map.json` は変更不要です。

## 注意
- 画面の「20日」「21日」選択は従来どおり有効です。両日出展の判定自体は他の日も確認しています。
- お気に入り、訪問順、メモ、訪問済みの保存キーと内容は変更していません。
- 店舗名の表記が日によって異なる場合、別店舗として判定されることがあります。
- GitHub Pagesのブラウザキャッシュが残ったときはページを再読み込みしてください。
